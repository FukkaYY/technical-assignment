# 学生詳細

## 目的

企業担当者が学生プロフィールの全体を確認し、メッセージ送信の判断を行えるようにする。

## 優先度・区分

- 優先度: P0
- 設計判断: 認証済み企業だけが閲覧できる。

## 表示項目

- 氏名
- 学校名
- 卒業予定年
- 興味のある職種（複数）
- スキル一覧
- 自己PR、学生時代に力を入れたこと、研究・ゼミ内容、英語スキル、保有資格（入力済みの項目だけ）
- メッセージ作成導線

学生のメールアドレス、内部ユーザーID以外の認証情報は表示しない。

一覧・詳細・メッセージ送信では `users.id` を共通の学生IDとして使用する。

## API

`GET /api/v1/students/:id`

- 成功: `200 OK`
- 未ログイン: `401 Unauthorized`
- 学生ロール: `403 Forbidden`
- 対象なし: `404 Not Found`

成功レスポンスの `data` は基本プロフィールに加え、`self_promotion`, `student_achievement`, `research_summary`, `english_skills`, `qualifications` を返す。画面では空のアピール項目を表示しない。移行互換用の `self_introduction` も当面返す。

## 画面状態

- 読み込み中
- 詳細表示
- 404
- APIエラー

未ログイン時は企業ログインへ、学生ロール時は学生マイページへ移動する。通信エラーはメッセージと再試行ボタンを表示し、404は通信エラーと区別する。一覧へ戻る導線は各状態で表示する。

## メッセージ導線

企業側メッセージ機能の実装後は「この学生にメッセージを送る」から `/students/:id/messages` へ移動する。

## 受け入れ条件

- 一覧で選択した学生のプロフィール全文を確認できる。
- 詳細画面から対象学生へのメッセージ作成へ進める。
- 存在しない学生IDでは404表示になる。
- メールアドレスを企業向けレスポンスに含めない。
- 読み込み、404、通信エラーを画面上で区別できる。
- 通信エラーから再試行でき、常に学生一覧へ戻れる。
- メッセージ送信画面へ対象学生IDを保持して移動できる。
