# 学生プロフィール編集

## 目的

登録済みの学生が、企業へ公開される自分のプロフィール情報を最新の状態に更新できるようにする。

## 優先度・区分

- 優先度: P1
- 区分: 設計判断
- 対象: 認証済みの学生本人

## 編集項目

- 姓・名（別項目）
- 学校種別と学校名（登録済みマスターから選択）
- 大学の学部・学科、または大学院の研究科・専攻（任意、連動選択）
- 卒業予定年
- 興味のある職種（1〜3件の複数選択）
- スキル
- 自己PR（任意、2,000文字以内）
- 学生時代に力を入れたこと（任意、2,000文字以内）
- 研究・ゼミ内容（任意、2,000文字以内）
- 英語スキル（任意、1,000文字以内）
- 保有資格（任意、1,000文字以内）

メールアドレス、パスワード、roleはプロフィール編集の対象に含めない。入力検証と正規化は学生登録時と同じ規則を使う。学校変更時は所属選択をリセットする。

## API

`PATCH /api/v1/student_profile`

リクエスト:

```json
{
  "student_profile": {
    "last_name": "山田",
    "first_name": "太郎",
    "school_id": 1,
    "faculty_id": 2,
    "department_id": 3,
    "graduation_year": 2028,
    "interested_roles": ["ソフトウェアエンジニア", "プロダクトマネージャー"],
    "skills": ["Ruby", "Rails"],
    "self_promotion": "チーム開発を得意としています。",
    "student_achievement": "学園祭アプリを開発しました。",
    "research_summary": "分散システムを研究しています。",
    "english_skills": "TOEIC 800点",
    "qualifications": "基本情報技術者"
  }
}
```

- 成功: `200 OK` と更新後の `data` を返す。
- 入力不正: `422 Unprocessable Entity`。保存済みプロフィールは変更しない。
- 未ログイン: `401 Unauthorized`。
- 企業ロール: `403 Forbidden`。
- CSRFトークンのない更新は拒否する。

## 画面

- 学生マイページから編集画面へ移動する。
- 編集画面は現在値を初期表示する。
- 説明文に「より良い企業さんとマッチするために、あなたについてアピールしましょう！」を表示する。
- キャンセルボタンは表示幅にかかわらず途中で改行せず、学生マイページへ戻る。
- 更新成功後は学生マイページへ戻り、完了メッセージと更新後の概要を表示する。
- 入力不正時は項目ごとのエラーを表示し、入力内容を保持する。
- 未ログインは学生ログイン、企業ロールは学生一覧へ誘導する。

## 対象外

- メールアドレス・パスワード変更
- プロフィール画像
- プロフィール公開停止（`profile-visibility.md` の専用機能として扱う）
- 管理者による編集

## 受け入れ条件

- 学生本人が編集対象の全項目を更新できる。
- 前後空白、空のスキル、重複スキルが登録時と同様に正規化される。
- 入力不正時に保存済みプロフィールが変更されない。
- 未ログインと企業ロールから更新できない。
- 更新後の学生マイページと企業向け学生一覧・詳細に変更が反映される。
- 企業向け詳細には入力済みのアピール項目だけを表示し、一覧の抜粋には自己PRを優先して使う。
- 既存の自己紹介は移行時に自己PRへ引き継ぐ。
