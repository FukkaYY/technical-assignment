# 学生登録

## 目的

学生本人が認証アカウントとプロフィールを作成し、企業が閲覧できる候補者として登録される。

## 入力項目

| 項目 | 必須 | 制約 |
|---|---:|---|
| 姓 / 名 | 必須 | 別項目、各50文字以内。国籍や文字種は制限せず、表示時は半角空白で結合 |
| メールアドレス | 必須 | 形式確認、大文字小文字を無視して一意 |
| パスワード / 確認 | 必須 | 8文字以上、確認値と一致 |
| 学校種別 | 必須 | 高専、専門学校、短期大学、大学、大学院 |
| 学校名 | 必須 | 選択した種別の学校マスターを検索して選択。自由入力不可 |
| 学部・研究科 | 任意 | 大学・大学院だけに表示し、選択した学校に属するマスターから選択 |
| 学科・専攻 | 任意 | 選択した学部・研究科に属するマスターから選択 |
| 卒業予定年 | 必須 | サーバー上の現在年から現在年+2までの選択式 |
| 興味のある職種 | 必須 | 定義済み候補から1〜3件。「まだ決めていない」は単独選択 |
| スキル | 任意 | 1項目50文字以内、最大20件 |

自己紹介は登録時に求めず、登録後のマイページで未登録を案内する。プロフィール編集では任意、2,000文字以内とする。

## 画面

- 姓と名だけをPCで横並びにし、モバイルでは縦に並べる。その他の入力欄は常に縦に並べる。
- 学校種別を選択後、学校名の入力で候補を絞り、候補リストから学校を確定する。
- 学校を変更した場合は学部・研究科と学科・専攻をリセットする。
- 大学は「学部」、大学院は「研究科」と表示する。高専・専門学校・短期大学では所属選択を表示しない。
- 興味のある職種は選択チップで最大3件まで選ぶ。「まだ決めていない」を選ぶと他の選択を解除する。

## API

- `GET /api/v1/education_options`: 未認証で学校種別と学校・学部・学科のマスターを取得する。
- `POST /api/v1/student_registrations`: アカウントとプロフィールを同一トランザクションで作成し、自動ログインする。
- サーバー側で `role=student` を設定する。
- 学校、学部・研究科、学科・専攻の存在と親子関係をRailsで検証し、不正なIDや組み合わせは422とする。
- 成功時のプロフィールは分割氏名とマスターIDに加え、表示用の `name`, `school_name`, `faculty_name`, `department_name` を返す。

## データと対象範囲

- プロトタイプ用の架空学校と、大学・大学院の少数の所属候補をseedする。
- 全国学校データの取り込みと、利用者による自由追加は対象外とする。
- 既存クライアントとの表示互換のため `name` と `school_name` を保持し、選択された正規データから同期する。

## 受け入れ条件

- 正しい入力でユーザーとプロフィールを作成し、登録直後にログイン状態になる。
- 学校マスターに存在しない学校や、学校と所属が一致しない組み合わせを登録できない。
- 卒業予定年は表示された3年分以外をAPIでも登録できない。
- 登録画面に自己紹介欄がなく、登録後のマイページで入力を促す。
- プロフィール作成失敗時にユーザーだけが残らない。
