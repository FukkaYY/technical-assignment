# 学生プロフィールの公開管理

## 目的

学生本人が企業向けプロフィールの公開状態を管理し、就職活動を休止したい場合に企業からの新規発見と接触を止められるようにする。

## スコープ

- 優先度: P1追加
- 操作者: ログイン中の学生本人
- 初期状態: 公開
- 公開状態は学生マイページに常時表示する。

## 公開停止

- 学生は専用APIで公開・非公開を切り替える。
- 非公開プロフィールは企業向け学生一覧、検索結果、学生詳細から除外する。
- 企業が非公開学生の詳細URLを直接指定した場合も404を返す。
- 非公開後は、その企業との既存会話がない場合、学生別メッセージAPIも404を返し、新しい会話を開始できない。

## 維持するデータと操作

- 公開停止はプロフィールや関連データを削除しない。
- 既存の1対1会話、面談予定、メッセージ履歴は維持する。
- 既存会話の参加者は、非公開後も閲覧・送信・予定操作を継続できる。
- 再公開すると企業向け一覧、検索、詳細へ再び表示する。

## API

- `PATCH /api/v1/student_profile/visibility`
- 入力: `student_profile.visible_to_companies`（boolean）
- 成功時は更新後の本人向けプロフィールを返す。
- 未ログインは401、企業ロールは403、CSRFトークン不正は422とする。

## 対象外

- 公開期間の予約
- 特定企業だけを対象にした公開・ブロック
- アカウント削除

## 受け入れ条件

- 学生がマイページから非公開にすると、企業の一覧・検索・詳細から見えなくなる。
- 非公開でも既存の1対1会話と面談予定を利用できる。
- 再公開すると企業の一覧・検索・詳細へ戻る。
- 本人以外は公開状態を変更できず、変更にはCSRFトークンが必要となる。
