# API共通仕様

## 基本方針

- ベースパス: `/api/v1`
- 形式: 原則JSON。募集の画像アップロードだけは `multipart/form-data`、画像取得は画像バイナリを返す。
- 日時: ISO 8601、UTC
- 認証: セッションCookie
- JSONキー: `snake_case`
- Cookie認証の変更系リクエストは、取得済みのCSRFトークンを `X-CSRF-Token` ヘッダーで送信する。

## 成功レスポンス

単一リソースは `data`、一覧は `data` と `meta` を返す。

```json
{
  "data": {},
  "meta": {}
}
```

## エラーレスポンス

```json
{
  "errors": [
    {
      "field": "email",
      "code": "taken",
      "message": "このメールアドレスは既に登録されています"
    }
  ]
}
```

一覧APIのページ番号が0、負数、整数以外の場合は、`field=page`, `code=invalid` の `422` を返す。

## ステータスコード

| 状況 | コード |
|---|---:|
| 取得成功 | 200 |
| 作成成功 | 201 |
| 削除成功・本文なし | 204 |
| 未ログイン | 401 |
| 権限不足 | 403 |
| 対象なし | 404 |
| 入力不正 | 422 |
| 試行制限 | 429 |
| 想定外エラー | 500 |

## ログ

- パスワード、Cookie、CSRFトークンを記録しない。
- 500エラーには追跡用IDを付与する案を検討する。
- ユーザー向けレスポンスにスタックトレースを含めない。
