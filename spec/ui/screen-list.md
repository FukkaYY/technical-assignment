## 共通状態

各データ取得画面は、少なくとも次を扱う。

- 読み込み中
- 正常表示
- 空状態
- 401によるログイン誘導
- 403による権限エラー
- 404
- 予期しないAPIエラーと再試行

## ナビゲーション

- ロールに応じて利用可能なメニューだけを表示する。
- 画面を隠すだけで認可を代替せず、API側でも検証する。
- ログアウトは学生・企業の両方から実行できる。
- ログイン済みで企業ログイン画面へアクセスした場合、企業は学生一覧へ移動する。学生には企業ログインフォームを表示し、企業アカウントへ切り替えられるようにする。
- S-005は企業名、S-016と募集管理への導線、赤系で区別したログアウト導線、学校種別・学校名・卒業予定年・興味のある職種による選択式の絞り込み、学生カード、現在ページ、総ページ数、前後ページへの導線を持つ。
- S-006は全プロフィールとS-007への導線、学生一覧へ戻る導線を持つ。
- S-007は対象学生名、送信者付きの古い順の会話履歴、本文入力、面談予定の提案・状態・取消を持つ。
- S-003は上部にS-008を主操作とするナビゲーションを置き、募集一覧とS-011への導線を並べる。プロフィール概要と企業への公開状態・切替操作を本文に表示し、ログアウトは赤系の専用ボタンとして通常操作から区別する。
- S-002は姓・名だけを横並びにし、学校種別、検索、学校、任意の所属を連動選択する。卒業予定年は3年分から選び、自己紹介は表示しない。
- S-003は5つのアピール項目がすべて空の場合、プロフィール編集からの追加入力を案内する。
- S-003は未読の企業メッセージがある場合、全会話の未読合計を白背景・赤い左線の上部通知と、赤背景・白文字の受信導線バッジへ表示する。
- S-008は企業名、最新本文の抜粋、最新送信日時、企業からの未読件数を持ち、新しい会話から表示する。
- S-009は企業名、送信者付きの古い順の会話履歴、返信フォームを持ち、表示済みの最新メッセージまで既読にする。面談予定が1件以上ある場合だけ、状態・承諾・辞退を表示する。
- S-011は現在の分割氏名・学校・所属、5つのアピール項目、マッチングを促す説明、項目別エラー、更新中状態、改行しないキャンセルボタンを持つ。
- S-012は自社募集のサムネイル、公開状態、作成・編集・募集終了導線を持つ。
- S-013は募集項目、サムネイルの登録・変更・削除、文字数、項目別エラー、保存中状態を持つ。
- S-014は公開中の募集を新着順で表示し、すべて・気になる募集の切替、気になる登録・解除、S-015への導線を持つ。
- S-015はサムネイル、企業名、募集項目の全文、気になる登録・解除を表示する。
- S-016は自社の会話だけを最新活動順で表示し、学生名、最新本文の抜粋、最新送信者、送信日時、S-007への導線を持つ。
