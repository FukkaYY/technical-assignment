# 主要ユーザーフロー

## 学生登録・受信

```text
トップ
  → 学生の方はこちら（学生ログイン）
  → 学生登録
  → 学校・所属マスターから選択、卒業予定年を3年分から選択
  → 入力検証
  → アカウント・プロフィール作成
  → 自動ログイン
  → 学生マイページ
  → 未入力なら自己紹介の追加を案内
  → 受信一覧
  → 受信詳細
```

登録済み学生はトップから学生ログインへ進み、認証成功後に学生マイページから同じ受信一覧・受信詳細へ移動する。

## 企業によるスカウト

```text
企業ログイン
  → 資格情報と企業ロールを検証
  → 学生一覧
  → 学生詳細
  → メッセージ作成
  → 送信
  → 送信結果・会話履歴
```

学生一覧の実装前は、同じ `/students` に企業名、ログイン成功状態、ログアウト導線だけを表示する。

## 認証エラー

```text
保護画面へアクセス
  → APIが401を返す
  → ログイン画面へ誘導
  → ログイン成功後に適切な開始画面へ遷移
```

## 権限エラー

```text
異なるロールのAPIへアクセス
  → APIが403を返す
  → 権限エラー画面を表示
```

## P1で追加するフロー

- 学生プロフィールの公開管理

```text
学生マイページ
  → プロフィールを非公開
  → 企業の一覧・検索・詳細から除外
  → 既存の1対1会話と面談予定は継続利用
  → プロフィールを再公開
  → 企業の一覧・検索・詳細へ復帰
```

- 学生プロフィール編集

```text
学生マイページ
  → プロフィール編集
  → 現在値を変更
  → 入力検証
  → 学生マイページ
  → 更新完了表示
```

- 学生検索・絞り込み

```text
学生一覧
  → 学校種別・学校名・卒業予定年・興味のある職種を選択
  → 検索
  → 条件付き学生一覧
  → 条件を維持してページ移動、または条件をクリア
```

- 企業のメッセージ一覧

```text
学生一覧
  → メッセージ一覧
  → 学生ごとの最新メッセージを選択
  → 既存の会話履歴・送信画面
```

- 学生からの返信

```text
受信詳細
  → 返信本文を入力
  → 送信
  → 自分の返信を会話履歴へ反映
```

- 学生側の未読管理

```text
企業がメッセージを送信
  → 学生の受信一覧に未読件数を表示
  → 受信詳細を表示
  → 表示した最新メッセージまで既読
  → 受信一覧から未読表示を解除
```

## P2で追加するフロー

- 企業の募集掲載

```text
企業の学生一覧
  → 募集管理
  → 任意のサムネイルを付けて募集作成・即時公開
  → 必要に応じて画像を含む編集または募集終了

学生マイページ
  → 公開中の募集一覧
  → 気になる登録
  → 気になる募集だけに絞り込み
  → 募集詳細
  → 気になる登録・解除
```

- 面談予定の調整

```text
企業側の会話画面
  → 日本時間で面談予定を提案
  → 学生側の会話画面に回答待ちとして表示
  → 学生が承諾または辞退
  → 双方の会話画面に確定した状態を表示

回答前であれば企業が取り消し
```
